# MCP 실사용 검증 기록 (Phase 5 / Task 5.2)

이 문서는 **작가가 직접 채우는 기록지**입니다. 코드로 대신할 수 없는 항목이라 템플릿만 준비했습니다.

**왜 필요한가:** Phase 6에서 컴패니언을 지웁니다. 지우고 나서 "그건 컴패니언으로만 되던 건데"를 발견하면 되돌릴 방법이 없습니다. 지우기 전에 MCP만으로 한 작품 분량을 실제로 써 보는 것이 유일한 확인 방법입니다.

**종료 조건:** 씬 10개 이상을 MCP 경로만으로 집필했고, 아래 "빠진 기능" 목록이 비었거나 수용 가능하다고 판단됨.

---

## 준비

- [ ] 설정 → 외부 에이전트 연결(MCP)에서 `full` 모드로 켠다
- [ ] 작품 제한(`mcp_project_id`)을 검증용 작품 하나로 걸어 둔다 — 실수로 다른 원고를 건드리지 않게
- [ ] Claude Code: 설정 화면의 `claude mcp add` 한 줄을 붙여넣는다
- [ ] Claude Desktop: `claude_desktop_config.json`에 스니펫을 넣는다
- [ ] 컴패니언 패널은 열지 않는다 — 검증 기간에는 MCP 경로만 쓴다
